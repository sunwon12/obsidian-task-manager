# Manual QA — DOING 타이머 알림 배너 (T-901, task_01KZN31H)

jsdom으로 검증할 수 없는 시각·감각 요구사항 체크리스트.
자동화 스펙: `tests/services/TaskTimerService.test.ts`, `tests/ui/timer/TimerNotificationStack.test.tsx`.

### 메뉴바 재클릭·초기 로딩 회귀

- [ ] Obsidian을 완전히 재시작한 뒤 TaskMaster 캐릭터 아이콘이 정확히 하나만 남는다.
- [ ] 플러그인 리로드와 새 Obsidian renderer 창 생성 뒤에도 아이콘은 하나이며 그 하나가 매번 열린다.
- [ ] 열린 패널에서 메뉴바 아이콘을 다시 누르면 재오픈 없이 한 번에 닫힌다.
- [ ] 닫힌 패널에서 메뉴바 아이콘을 누르면 한 번에 열린다.
- [ ] 내용이 패널 높이를 넘으면 휠/트랙패드로 끝까지 스크롤되고, 타이머 갱신 뒤에도 현재 위치가 유지된다.
- [ ] 플러그인 리로드 뒤 TaskMaster 보드가 장시간 0개로 머물지 않고 기존 카드가 복원된다.

> v0.9.1부터 Obsidian 창 위 배너는 기본 UI로 마운트하지 않는다. 아래 배너 항목은 보관된 컴포넌트의 회귀 체크이고, 현재 실사용 계약은 **macOS 메뉴바 빠른 작업 패널만 자동 표시**하는 것이다.

## 현재 Obsidian 창 계약 (v0.9.1)

- [ ] DOING 태스크가 있어도 Obsidian 우상단에 타이머 배너가 자동으로 뜨지 않는다.
- [ ] 타이머 상세·단계 입력은 macOS 메뉴바 스톱워치 좌클릭으로만 연다.
- [ ] 사용자가 메뉴바 우클릭으로 `컴퓨터 화면에 고정`을 선택한 경우에만 별도 타이머 창이 뜨는다.

## 작업 계획·현재 단계

- [ ] 태스크 생성/편집 창에서 단계를 입력하면 frontmatter `step1`, `step2`, ... 개별 문자열 속성으로 저장된다.
- [ ] 예전 `steps` 목록을 가진 task도 정상적으로 읽히고, 다음 저장 시 번호별 속성으로 변환된다.
- [ ] DOING 타이머의 시간 아래에 단계가 보이고, `currentStep` 이전은 ✓, 현재는 →, 이후는 번호로 보인다.
- [ ] 타이머가 돌아가는 동안 task Markdown의 `currentStep` 숫자를 바꾸면 재시작 없이 표시가 갱신된다.
- [ ] 타이머의 임의 단계를 클릭하면 바로 현재 단계로 강조되고 task Markdown의 `currentStep`에도 저장된다.
- [ ] 태스크 생성/편집 창은 `1단계`, `2단계` 개별 입력과 단계 추가·삭제 버튼을 보여준다.
- [ ] 7단계 이상인 계획도 배너 내부에서 잘리지 않고 모두 보인다.
- [ ] Obsidian 기본 속성 패널이나 외부 AI가 `stepN`/`currentStep`을 수정하면 실행 중인 타이머에 즉시 반영된다.
- [ ] 타이머 실행 중 각 단계 오른쪽에 해당 단계의 누적 시간이 초 단위로 갱신된다.
- [ ] 단계 클릭 또는 외부 `currentStep` 변경 시 이전 단계 시간이 멈추고 새 단계 측정이 시작된다.
- [ ] 일시정지·스탑 시 `step1Seconds`, `step2Seconds`, ... 숫자 속성이 task Markdown에 저장된다.
- [ ] Obsidian을 재시작해도 진행 중이거나 일시정지된 단계별 시간이 복원된다.
- [ ] 현재 단계 박스는 테마 강조색 배경으로 다른 단계와 명확히 구분된다.
- [ ] 긴 URL/단계명은 배너 밖으로 넘치지 않고 `…`로 줄여 보이며 hover 시 전체 내용을 확인할 수 있다.

## 컴퓨터 화면 고정

- [ ] 화면 고정 버튼은 별도 상단 막대가 아니라 각 태스크 타이머의 제목·시간 헤더 안에 원형 아이콘으로 보인다.
- [ ] 고정 아이콘을 누르면 Obsidian을 다른 앱 뒤로 보내도 컴퓨터 화면 우상단에 타이머 창이 유지된다.
- [ ] 외부 창에는 태스크 제목, 전체 시간, 단계 목록, 현재 단계 강조색, 단계별 시간이 표시된다.
- [ ] 외부 창의 단계 행을 클릭하면 해당 단계가 즉시 현재 단계로 저장되고 강조가 이동한다.
- [ ] 외부 창 헤더의 재생/일시정지·완료·× 버튼이 각각 타이머 제어와 화면 고정 해제로 동작한다.
- [ ] 외부 창의 긴 태스크명/단계명은 창 밖으로 넘치지 않고 `…` 처리된다.
- [ ] 고정 아이콘을 다시 누르거나 플러그인을 끄면 외부 창이 즉시 닫힌다.
- [ ] 모바일 또는 Electron remote 미지원 환경에서는 고정 아이콘이 표시되지 않고 기존 배너는 정상 동작한다.
- [ ] macOS 메뉴바의 TaskMaster 항목을 열면 태스크 목록 위에 `컴퓨터 화면에 고정/화면 고정 해제`가 보이고 동작한다.
- [ ] 플러그인을 여러 번 리로드해도 macOS 메뉴바 TaskMaster 아이콘은 하나만 추가된다.

## 화면 위치·모양 (맥북 슬랙 알림창 스타일)

- [ ] 배너가 Obsidian 창 **우상단**에 고정으로 뜬다 (에디터·다른 노트를 열어도, TaskMaster 뷰를 닫아도 보인다).
- [ ] 배너는 **가로로 긴 직사각형** — 맥 알림 배너 비율(대략 360×80px 내외), 둥근 모서리 + 그림자.
- [ ] 여러 태스크가 DOING이면 배너가 **하나씩 세로로 스택**되고, 최신이 맨 위. 간격 일정.
- [ ] 다크/라이트 테마 모두에서 배경·글자 대비가 자연스럽다 (Obsidian CSS 변수 사용).
- [ ] 제목이 길면 말줄임(…) 처리되고 배너 폭이 늘어나지 않는다.

## 등장·퇴장 애니메이션

- [ ] DOING 진입 시 오른쪽에서 슬라이드 인 (슬랙 알림 느낌).
- [ ] 스탑/이탈 시 부드럽게 사라지고, 아래 배너들이 자연스럽게 위로 당겨진다.

## 스와이프 닫기

- [ ] 마우스 드래그로 오른쪽으로 밀면 배너가 따라 움직인다 (손가락에 붙는 느낌).
- [ ] 임계값(80px) 이상에서 놓으면 오른쪽으로 날아가며 닫힌다.
- [ ] 임계값 미만에서 놓으면 원위치로 스냅백한다.
- [ ] 왼쪽으로는 밀리지 않는다 (맥 알림과 동일).
- [ ] 스와이프 도중 버튼이 눌리는 오작동이 없다.

## 타이머 동작

- [ ] 스타트 → 1초 간격으로 경과 갱신. 정지 → 동결 + 재개 버튼. 스탑 → 태스크가 DONE 컬럼으로 이동.
- [ ] 스탑 후 태스크 Markdown frontmatter에 `actualMd`가 MD 환산값으로 기록된다 (기존 값이 있으면 합산, 카드에도 표시).
- [ ] 배너의 스탑과 보드에서의 컬럼 이동이 서로 어긋나지 않는다 (이중 이동·유령 배너 없음).
- [ ] macOS 잠자기/깨어남 후에도 경과가 벽시계 기준으로 맞다 (setInterval 누락에 영향받지 않음).

- [ ] 플러그인 로드 시 메뉴바에 배경이 투명하고 여백 없이 꽉 찬 22pt TaskMaster 랏코 아이콘이 정확히 하나 뜬다.
- [ ] 타이머가 생기거나 상태가 바뀌어도 랏코 옆에 `⏱/▶/⏸ 00:00`이나 개수 텍스트가 붙지 않는다.
- [ ] 실행 중 Stop을 누르지 않고 Obsidian을 리로드/종료해도 종료 시각까지의 전체·현재 단계 시간이 저장되고 다시 로드된다.
- [ ] **Obsidian이 백그라운드여도(다른 앱 사용 중) 메뉴바 표시가 계속 갱신된다.**
- [ ] 아이콘 좌클릭 → 메뉴바 바로 아래에 둥근 다크 팝오버가 열리고, 화면 바깥으로 잘리지 않는다.
- [x] 명령 팔레트의 `Open TaskMaster quick panel`로도 같은 팝오버가 열린다 (2026-08-22 실기기 확인).
- [ ] 팝오버에 오늘 날짜·진행/완료 수·현재 작업/단계·다음 할 일이 정보 위계대로 보인다.
- [ ] 현재 작업의 단계 입력창에 한글을 쓰고 Return을 누르면 팝오버에서 즉시 행이 추가되고 task Markdown에 `stepN`으로 저장된다.
- [ ] 단계 입력 중 타이머가 1초마다 갱신되어도 포커스와 작성 중인 문장이 유지된다.
- [ ] 다음 할 일의 재생 버튼을 누르면 DOING으로 이동하며 타이머가 시작된다.
- [ ] 빠른 할 일 입력창에서 만든 카드는 TODO에 생성된다.
- [ ] `TaskMaster 전체 보드 열기`를 누르면 Obsidian의 TaskMaster 뷰가 열린다.
- [ ] 팝오버 밖을 클릭하거나 Escape를 누르면 닫힌다.
