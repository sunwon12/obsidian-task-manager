# TaskMaster Ratko 개발 규칙

이 파일은 저장소 상위 지침을 상속하며, `native/TaskMasterRatko/` 아래 Swift 앱에 다음 규칙을 추가한다.

## 사용자 요구는 UX가 완결된 상호작용으로 구현한다

- 사용자가 말한 기능만 화면에 노출하고 끝내지 않는다. 그 기능에 들어가는 방법, 성공·실패 피드백,
  저장, 취소, 포커스 이탈, 바깥 클릭, `Esc`, 창 닫기와 재실행까지 일반적인 macOS 사용 흐름을 함께
  설계한다.
- 편집·선택·드래그 같은 임시 모드는 사용자를 가두지 않는다. 다른 곳을 클릭하면 종료하고, 유효한
  변경은 안전하게 저장한다. 명시적 취소는 저장하지 않으며 원래 값을 보존한다.
- 요구사항의 글자 그대로와 사용자가 실제로 하려는 일을 함께 검증한다. 좁은 메뉴바 패널에서도
  조작법이 발견 가능해야 하고, 클릭 결과와 현재 상태가 즉시 보여야 한다.
- 문구나 순서를 바꾸는 UI는 타이머·선택·누적 시간처럼 사용자가 유지되리라 기대하는 상태를 보존한다.
  파괴적이거나 되돌리기 어려운 동작은 별도 확인 없이 추론해 실행하지 않는다.
- 완료 전에 정상 경로만 보지 않는다. 최소한 진입 → 수정 → 저장, 취소, 바깥 클릭, 빈 값·오류,
  라이브 갱신 중 상태 보존을 확인하고 관련 계약 테스트를 남긴다.
